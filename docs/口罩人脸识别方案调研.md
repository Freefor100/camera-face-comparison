## 1. 归档结论与范围

本次曾考虑把“戴口罩时仍能识别身份”作为课程扩展。约束是完全离线、本地加载现成权重，不自行训练或微调。经讨论，暂不继续实施：完整接入不仅涉及替换模型，还涉及对齐适配、标准库特征重建、口罩数据整理、开放集阈值标定及普通脸回归验证；局部匹配和双路径方案又会增加存储、候选排序和状态管理成本。

这是项目范围选择，不表示技术上不可实现，也不表示必须自行训练。本文只保留研究痕迹，不新增代码、依赖、模型文件、数据集、测试、配置项或待办事项。

当前实现仍以 [系统设计](../design.md)、[模型与标准库数据流](InsightFace模型与标准库数据流.md) 和 [阶段 5B 结果](experiments/phase-5b-cross-quality-results.md) 为准。现有多帧择优、检索及流水线优化不等于已经完成口罩专项验证。任务书中的遮挡检测鲁棒性方向，也不能直接等同于完整的口罩身份识别能力；参见 [任务书要求提取](任务书要求提取.md)。

核心判断如下：

- 戴口罩识别不等于降低接受阈值。阈值不改变特征，也不改变同一评分规则下的候选排序。
- 不自行训练，可以使用作者训练好的模型，也可以研究冻结模型的输入或匹配适配。
- 口罩检测器不是所有方案的必要组件。统一模型、内部遮挡分支和外部条件分流是不同设计。
- 五点对齐、512 维输出都不因口罩而必然失效；关键是检测、对齐和身份表示是否可靠。
- 没有本项目统一协议的实验，不能说任一候选明显优于 `buffalo_l`，也不能宣布“最强方案”。

## 2. 基本概念与现有系统

### 2.1 三个不同任务

| 任务 | 回答的问题 | 典型输出 |
| --- | --- | --- |
| 人脸检测与关键点定位 | 脸在哪里，如何对齐？ | 人脸框、检测分数、关键点 |
| 口罩状态检测／遮挡分割 | 是否戴口罩，哪里被挡住？ | 状态概率或像素区域 |
| 身份识别 | 是标准库中的谁，还是未知人员？ | 身份特征、候选分数、接受／拒绝结果 |

一个口罩分类数据集只有“戴／未戴”标签时，不能直接用于身份识别评测。人脸检测成功也不等于身份判断正确。

现有主流程是：

```text
摄像头或本地图片
  → 单人脸检测与五点定位
  → 对齐图像
  → buffalo_l 中的识别模型提取单位特征向量
  → 与每人的平均特征向量做余弦比较
  → 最高分阈值判定
  → 姓名／未知人员；输入失败单独处理
```

当前模型适配见 [face_engine.py](../src/camera_face_comparison/face_engine.py)，人员表示与检索见 [face_library.py](../src/camera_face_comparison/face_library.py)。摄像头采用五帧检测、清晰度择优，通常只对最终选中帧提取一次身份特征；它不是五次独立身份判定投票。

### 2.2 五点、身份向量与 ArcFace

左右眼、鼻尖、左右嘴角用于估计对齐变换。口罩下仍可预测鼻嘴位置，但这些被遮挡点是估计值，不是对真实鼻嘴外观的观测。预测误差可能带偏整个裁剪；更换身份模型不能自动修复上游漏检或对齐错误。[1]

识别网络读取的是对齐后的图像像素，不是五个坐标。512 维向量也没有固定的“眼睛维度”和“嘴巴维度”，不能删除若干维度来去掉口罩影响。直接把五点改成两点、把缺失坐标填零，均不等价于可靠的遮挡对齐。

ArcFace 是加性角度间隔损失，不是唯一的网络结构或模型文件。训练时目标类别分数由 `s*cos(theta_y)` 改成 `s*cos(theta_y+m)`，配合分类损失学习身份表示；推理通常去掉分类头，再比较身份向量。不同骨干、训练数据和权重都可能被称作“ArcFace 模型”。训练间隔 `m` 不是部署接受阈值。[1]

### 2.3 训练、校准与登记不能混称

| 操作 | 是否改变网络权重 |
| --- | --- |
| 作者使用普通／口罩图片训练模型或附加模块 | 是 |
| 下载这些权重，在本地执行前向推理 | 否 |
| 在参数选择集选择阈值、遮挡区域、融合系数 | 否，但仍属于利用数据选择方案 |
| 给人员追加口罩参考照、重新计算平均特征 | 否，改变的是标准库表示 |
| 替换模型后重新提取所有参考图特征 | 否，执行的是新模型推理 |

“冻结基础模型”也不一定代表整个研究方法零训练：FFR-Net 和 EUM 仍训练附加模块。DeepFace-EMD 的局部匹配、规则归零则可以不新增网络训练。[2][5][8][9]

## 3. 方案总览

以下难度是相对本项目的定性工程判断，不是实测工时或速度。论文中的训练由作者完成；是否能够直接使用，仍取决于完整权重、预处理、运行依赖及许可。

| 方法 | 主要改动位置与原理 | 外部口罩分流 | 接入代价与限制 |
| --- | --- | --- | --- |
| 重新标定阈值 | 只改变接受边界 | 不必 | 低；不能改善特征可分性或候选排序 |
| 追加口罩参考照 | 改人员表示和参考覆盖 | 不必 | 低；当前功能可承载，但混合平均是否改善未验证 |
| 共同遮挡／Zeroing | 双方移除对应像素区域，继续用普通模型 | 保留普通路径时需要状态信息 | 简单固定模板低；四组合路由与混合图库中等 |
| MaskInv | 教师提供普通脸表示，学生学习普通／口罩身份一致性 | 不必 | 中低；完整学生网络仍输出身份向量 [6] |
| FROM | 预测特征掩码，抑制受遮挡污染的响应 | 不必，内部预测权重 | 中；需骨干、掩码分支与正确配置 [3] |
| MSML | 分割支路在多层引导识别特征处理 | 不必另加二分类器 | 中高；分割与识别需要配套权重 [7] |
| FFR-Net | 动态空间／通道矩阵重组，融合原始特征 | 不必 | 中；校正器只对配套编码器有依据 [2] |
| EUM／SRT | 将口罩身份向量转换到普通脸特征域附近 | 有路径区别 | 中高；依赖特定基础模型和口罩状态 [8] |
| DeepFace-EMD | 普通模型局部特征＋最优运输式匹配，重排候选 | 不必 | 高；需空间特征、局部缓存和人员级聚合 [5] |
| LVFace | 分阶段优化 Transformer 的通用身份表示 | 不必 | 中低；有 ONNX，但公开权重不等于论文最高分版本 [10] |
| TopoFR | 训练时约束特征结构关系并优化困难样本 | 不必 | 中；部署仍是身份特征提取 [11] |
| TransFace | 改进 Transformer 的数据增强和训练策略 | 不必 | 中；通用基准不能替代真实口罩评测 [12] |

IFLM、AMOFR、MoDE 也曾作为后续线索讨论，分别涉及交互特征学习、自适应遮挡适配、扩散专家与选择机制。它们的资料入口保留在文末，但本文不据此认定完整权重已经可用，也不作优于现有系统的结论。[18]

## 4. FFR-Net：矩阵从何而来，训练和推理如何区分

### 4.1 从输入到身份向量

以下是作者公开实现的结构摘要，不是给本项目新增的代码。[2]

```text
对齐人脸：3×112×112
  → 配套的预训练 IR-SE50 编码器（训练校正器时冻结）
  → 特征图 F：512×7×7；展开为 A：512×49
       ├─ 空间自相似：49×49
       │    → 与原特征拼接 → 卷积生成器 → Ms：49×49
       │    → 空间重组 As = A·Ms
       ├─ 通道自相似：512×512
       │    → 与原特征拼接 → 全连接生成器 → Mc：512×512
       │    → 通道重组 Ac = Mc·A
       │    → 与其水平翻转结果拼接 → 卷积／残差融合
       └─ 原始特征保留到最后的融合入口
  → 三路特征按通道拼接：1536×7×7
  → 卷积／残差融合：512×7×7
  → 7×7 平均池化
  → 512 维校正身份向量
```

空间自相似比较 49 个位置的通道向量；通道自相似比较 512 个通道的空间响应，二者使用余弦相似度。它们是当前图片内部的关系，不是与某张标准库照片配对计算。

空间生成器依次采用通道 `561→256→128→49` 的卷积与残差块；通道生成器沿最后一维采用 `561→32→512→32→512→32→512` 的线性变换。最后通过 sigmoid 产生系数，而不是做行和为 1 的 softmax。矩阵乘法进行跨位置或跨通道混合，不只是把某一个人脸部位乘小。

“拼接”本身没有学习参数，只把三路张量沿通道放在一起；后面的卷积和残差块才用训练好的参数重新组合它们。通道分支的水平翻转也不等于补出真实的遮挡五官。

### 4.2 怎样训练矩阵生成器

作者固定编码器参数并置于评估模式，联合训练校正生成器、融合网络和分类头。普通脸、合成口罩脸通过共享校正网络，使用身份保持、自相似关系、triplet 和身份分类损失。[2]

设普通脸原始向量为 `t_u`，校正后的普通／口罩向量为 `z_u`、`z_m`，身份保持项概括为：

$$
L_{id}=\tfrac12\bigl(\operatorname{MSE}(z_u,t_u)+\operatorname{MSE}(z_m,t_u)\bigr).
$$

没有人工标注的正确矩阵。最终损失经融合层和矩阵乘法反向传播到矩阵生成器，例如 `As=A·Ms` 的梯度包含 `A^T·(dL/dAs)`。这是可微计算带来的训练信号。

因此，准确表述是“新增校正网络端到端联合训练、原始编码器冻结”，而不是全部网络从头训练。部署时不再反向传播：参数固定，但不同图片会产生不同的 `Ms(x)` 和 `Mc(x)`。**动态输出不等于当场学习。**

普通脸保持损失只是软约束，不能保证其信息和准确率完全无损；也不能从向量接近推出“模型必然只看眼睛”。特征校正不能恢复图像中不可观察到的真实身份细节。

## 5. FROM：特征权重如何学习

FROM 的核心是从多尺度特征预测权重，抑制受遮挡影响的响应。以空间与通道联合掩码为例：[3][4]

$$
W(x)=\sigma(g_\theta(P(x))),\qquad F'(x)=W(x)\odot F(x).
$$

`P(x)` 是融合后的特征，`g_theta` 是权重预测网络，`W(x)` 是本张图的输出权重。作者实现还包含不同掩码形状的消融版本，使用时不能只按“FROM”这个名称随意选择输出。

训练通过身份损失和遮挡模式损失共同约束。合成遮挡的位置已知，可以生成遮挡模式标签；辅助分支从权重预测遮挡模式，身份分支要求加权后仍可区分人员。其概念形式为：

$$
L=L_{identity}+\lambda L_{pattern},\qquad
\frac{\partial L_{identity}}{\partial W_i}
=\frac{\partial L_{identity}}{\partial F'_i}F_i.
$$

梯度继续回传到 `theta`，使生成器学会输出有用的权重。无需给每一个特征元素标注正确权重，也无需手工宣布“某通道就是嘴巴”。[4]

空间位置存在感受野，对应一片重叠的输入区域；通道是学习到的响应模式，不是固定器官编号。深层响应可能被远处遮挡影响。因此“识别受污染特征”与“把原图嘴部像素缩小为同位置特征块”不是同一件事。

推理时所有参数保持固定。FROM 的内部掩码分支和 MSML 的分割支路，也不等于在应用外部先二分类，再选择两个人脸识别模型。

## 6. DeepFace-EMD：不训练识别网络的局部匹配

### 6.1 局部特征与相似度

普通网络一次前向可产生空间特征图 `C×H×W`。取位置 `(h,w)` 上的全部通道，得到一个局部向量；例如 `512×8×8` 对应 64 个 512 维向量。也可以按作者配置池化为更少位置。它不是把图像切成许多小图后各自重复识别。[5]

归一化后的查询局部 `q_i` 和参考局部 `r_j`，使用：

$$
s_{ij}=q_i^Tr_j,\qquad d_{ij}=1-s_{ij}.
$$

这里没有额外训练的局部相似度网络。APC 策略根据一侧局部与另一侧局部均值表示的正相关程度，计算并归一化局部权重。局部均值表示不应与另一个全局身份输出头混用。

### 6.2 加权匹配与候选重排

匹配矩阵 `T` 在双方局部权重约束下，倾向于降低总距离 `sum(T_ij*d_ij)`。代码采用 Sinkhorn 迭代计算近似运输匹配，并把局部分数与全局分数融合，重新排列初筛候选。[5]

求解本次匹配矩阵是数值优化，不会更新人脸网络参数。局部可以跨位置对应；这不代表已经检测出眼睛、鼻子等器官，也不保证所有对应都正确。

对本项目的主要代价是需要提取／缓存空间特征、扩展候选数量、设计多人多参考图的分数聚合，而不是只替换最终 512 维向量。当前每人一条平均向量、仅取前两名的实现不足以直接使用原方法。初筛没有召回的身份也不能靠重排找回。

原论文包含不训练重排与作者自己的口罩微调基线对照；它不是对 FROM、FFR-Net、MaskInv 或本项目 `buffalo_l` 的全面胜出证明。[5]

## 7. 共同遮挡设想：四种组合、收益与代价

### 7.1 讨论中的方案

以下是尚未实现的项目设想。先检测、对齐两张图，再决定共同遮挡区域。设查询图和参考图的不可见区域为 `M_q`、`M_r`，可以用并集 `M=M_q∪M_r`，保留双方共同可见的区域：

$$
x'_q=(1-M)\odot x_q+M\odot c,\qquad
x'_r=(1-M)\odot x_r+M\odot c.
$$

`c` 是两边一致的填充颜色或模板。用同一个冻结识别模型分别提取 `x'_q`、`x'_r` 的特征，再比较。

| 待识别图片 | 参考图片 | 共同遮挡分支的处理 |
| --- | --- | --- |
| 未戴口罩 | 未戴口罩 | 保留原始完整脸路径，不额外遮挡 |
| 戴口罩 | 未戴口罩 | 将查询的遮挡区域在双方统一替换 |
| 未戴口罩 | 戴口罩 | 将参考的遮挡区域在双方统一替换 |
| 戴口罩 | 戴口罩 | 双方使用遮挡区域并集，统一替换 |

不能只把普通图画黑而保留另一边真实口罩纹理，然后宣称已消除遮挡外观差异。对齐坐标只是近似对应相同部位，大姿态和关键点误差仍会破坏对应。

### 7.2 为什么可能有用，又为什么不保证有效

它减少两张图的遮挡外观差异，同时主动删除身份信息；同人分数可能上升，异人分数也可能上升。口罩颜色、印花不是稳定身份依据，但边界有助于判断可见区域，附近也可能存在有效面部信息。黑块或同款合成口罩对普通网络都是实际输入，不是自动抵消或被跳过的标记。

若普通—普通分支继续使用完全相同的模型、图像、人员表示，其成对分数可保持原样；但混合图库的候选竞争、分流错误和新阈值仍可能改变最终识别结果。它只避免该分支的额外特征处理，不保证整个系统无退化。

改变结构，让卷积或注意力明确读取有效性掩码，是另一类方案。即使某种改动不增加可训练参数，也会改变已有网络的计算分布，不能认为原始权重天然适用。本项目没有实施这种结构修改。

### 7.3 与已有研究、缓存结构的关系

Zeroing 论文研究在对齐后按鼻部位置移除下方像素、保持图像尺寸，使用冻结的普通识别模型。它为低成本输入适配提供了参考，但不是上述逐对并集方案，效果也取决于模型、数据和比较规则。[9]

固定遮挡模板可以为每张参考图预计算完整／遮挡两套特征，再分别按人员聚合；逐查询—参考图计算不同遮挡并集，则可能要反复重提取库特征。前者较易缓存，后者更灵活但代价更高。不能把完整和遮挡特征重新无差别平均后，还声称两个分支保持隔离。

## 8. 效果证据怎样比较

### 8.1 不同指标不能拼成总排名

| 证据 | 可以说明什么 | 不能直接说明什么 |
| --- | --- | --- |
| 普通 LFW、IJB-B/C | 指定协议下的通用身份验证能力 | 真实口罩专项能力 |

| 同一论文中的方法／消融对照 | 该数据、权重与协议下的相对变化 | 对不同数据训练的 buffalo_l 的必然优势 |
| 论文最佳模型分数 | 该训练版本的报告效果 | 仓库任一可下载权重的效果 |

MFR-Ongoing 将 Mask 与 MR-All 区分：Mask 使用口罩与普通脸配对；综合榜还包含多人群结果。因此总榜第一、MR-All 高分不能直接当作口罩第一。[13]

### 8.2 通用强模型与专项模型的边界

LVFace、TopoFR、TransFace 首先是通用表示改进，并非看到口罩就切换一套阈值。MaskInv、FROM、MSML、FFR-Net 等则明确针对口罩或遮挡设计。两类都可能成为候选，网络新旧、大小、是否含注意力不能单独决定结果。

LVFace 官方公开表区分 Glint360K 下载权重与尚未发布的 WebFace42M 条目。TopoFR 同样需要区分骨干和训练数据。不能把大训练集论文版本的口罩成绩，写到较小训练集公开权重名下。[10][11]

截至本次归档，没有本项目对这些确切权重的同条件实测，因此不作“明显强于 buffalo_l”或“当前最强”的结论。后续 MoDE 论文中的部分方法对照也不能替代完整、统一的本地评测。[18]

本文不保留对话中的动态引用数、仓库星标数或跨协议准确率总排名：它们不足以决定选型；精确数值应带论文表号、模型版本、训练数据、数据划分、指标和误接收约束核对后再引用。资料中自称的 SOTA 也只适用于作者报告的范围。

### 9.2 如果未来重新评估，证据应满足什么条件

本节仅记录判断标准，不是开发计划。

参数选择集与独立验证集按来源身份隔离；同一照片的原始／合成版本、同一视频的相邻帧不能跨分区。登记照片与待识别照片应不同，并加入从未登记的人员。旧的独立验证集一旦用于新方案选择，就不能继续声称它是新方案未见过的测试集。

四种口罩组合都需统计；先区分检测失败、对齐／特征失败、候选排序错误、正确候选低于阈值。已登记人员端到端正确接收率应包含前端失败，未登记人员误接收不能通过把检测失败计为正确拒识来美化。保留计数、身份数量、区间和端到端耗时，而不只写一个准确率。

统一识别模型可以先共同标定一个阈值，但要分别检验四组；双路径可以比较统一／分路径阈值。阈值数目、遮挡模板和融合系数也属于待选择参数。任一路径通过即接受会增加误接收机会，必须按最终联合系统复测；不能先把各分支分别调好，就假定合起来仍有相同风险。

## 10. 对现有流程的接入代价与未采用理由

| 接入方式 | 原流程可保留的部分 | 原则上需要改变的部分 |
| --- | --- | --- |
| 替换完整特征模型 | 摄像头、界面、单脸规则、日志；平均向量检索可作起点 | 模型适配、预处理、所有库特征重提取、阈值和性能复验 |
| 共同遮挡双路径 | 原检测和普通脸路径 | 遮挡模板／状态、两套特征与聚合、路由和跨路径候选判定 |
| EUM 等向量转换 | 指定基础模型的部分接口 | 严格配套的转换器、口罩状态、不同路径及对应库表示 |
| EMD 局部重排 | 普通全局特征初筛 | 中间特征输出、空间特征缓存、前 K 候选、多样本局部分数聚合、重排阈值 |

同样 512 维不代表同一特征空间。不同模型不可直接混比；更换识别器后必须重新编码原参考照片。模型输出若是专有模板，也不能当作浮点向量直接求均值。

若只替换完整预训练模型，通常无需额外口罩检测器；只有采用条件分流、模板选择或向量转换时才需要状态来源。口罩检测失败会成为新的系统失败点。已有五帧择优、数据完整性检查和性能优化也都不能替代这轮验证。

考虑这些工作量与当前课设已有成果，本阶段不再扩展。保留的三类思路是：普通模型输入适配、完整遮挡模型替换、局部匹配重排；不选定生产候选、不更新默认阈值、不承诺下一阶段实现。
