## 阶段 4：聚合方法与开放集判定联合标定

## 阶段 5：鲁棒性扩展、耗时与用户界面收尾

- [x] 使用 XQLFW 官方 6,000 对完成真实跨质量分析，并与原始 LFW 的同协议、共同有效图片对比较。
- [x] 删除逐图执行的未使用模型，并用独立空缓存全量复测：有效人脸特征向量平均耗时下降 26.0%，7,263 条结果零差异。
- [x] 完整处理 QMUL-SurvFace 242,453 张官方图片，记录原始模型覆盖、人脸特征提取失败、可评分分母，以及直接套用 LFW 规则后全部拒绝的现象；将监控小脸域列为系统限制。
- [x] **阶段 5B：**补齐 XQLFW 13,233 张同路径人脸特征向量，构造自然、跨质量待识别图片、混合质量标准库和全低质量压力场景。
- [x] **阶段 5B：**显式比较最高分阈值、仅候选分差、真正双条件和邻域感知余弦规则；在四个主要场景共同选择一套参数。
- [x] **阶段 5B：**在参数选择集内完成 3～100 人稳定性检查，冻结 `人员平均特征向量 + score_threshold, T=0.5557855` 后只运行一次评价集。
- [x] 把阶段 5B 冻结的人员平均特征向量和明确接收策略接入桌面应用，删除旧质量加权的前 K 个样本分数平均、分层阈值和基于数值指标的质量强制拒绝。
