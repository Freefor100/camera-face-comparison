# 阶段 2：固定评测数据与连续候选分数（历史阶段）

“连续候选分数”指尚未应用接收阈值的人员分数。统一术语见
[术语与内部命名](../术语与内部命名.md)。

## 1. 阶段目标

本阶段第一次把“模型特征提取”和“开放集接收判定”拆开，不再用一个主观初始阈值
直接比较聚合方法：

```text
固定 LFW 标准库与全部待识别图片
  → 在图片过滤前按来源身份划分参数选择集/独立验证集
  → 复用人脸特征向量缓存
  → 对每张有效待识别图片计算六种人员聚合结果
  → 保存第一候选、第二候选和候选分差，不保存接收参数
```

XQLFW 和 QMUL-SurvFace 当时不参与聚合选择，后续分别用于跨质量与监控小脸压力分析。

## 2. 固定协议

源协议覆盖 LFW 13,233 张图片：标准库 7,490 张，待识别图片 5,743 张。标准库身份的留出
图片是已登记人员图片，完全不进入标准库的身份图片是未登记人员图片。

`split_lfw_protocol()` 在图片过滤前按身份划分：

- 标准库在参数选择集与独立验证集中相同；
- 已登记人员按标准库身份分组；
- 未知人员按图片首级目录的来源身份分组；
- 固定种子 `2026`，50% 来源身份进入参数选择集，其余进入独立验证集；
- 同一已登记人员或未知人员来源身份不跨分区。

协议保存源协议 SHA-256、随机种子、比例、角色与全部相对路径。

## 3. 六种聚合候选

| 内部名称 | K | 人员分数定义 |
| --- | ---: | --- |
| `single` | 0 | 每个身份固定使用第一张有效参考样本 |
| `max` | 0 | 该身份全部参考样本相似度的最大值 |
| `mean_prototype` | 0 | 样本向量平均、重新归一化后与待识别图片点积 |
| `top_k_mean` | 2 | 最高 2 个样本相似度的普通平均 |
| `top_k_mean` | 3 | 最高 3 个样本相似度的普通平均 |
| `top_k_mean` | 5 | 最高 5 个样本相似度的普通平均 |

K=1 与最高样本分数重复。每人样本少于 K 时使用全部有效样本。

## 4. 历史产物

`data/experiments/phase2/decision_scores.sqlite` 当时保存：

- 参数选择集/独立验证集分区和待识别图片路径；
- 已登记人员真实身份或未知人员来源身份；
- 聚合方法和 K；
- 第一/第二候选身份、连续分数和候选分差；
- 已登记人员第一候选是否正确；
- 当时缓存携带的质量观测与拒绝原因；
- 评分耗时、协议哈希和代码版本。

实际覆盖为标准库 4,735 张有效、2,755 张拒绝；待识别图片 3,842 张有效、1,901 张拒绝；
六种聚合共 23,052 条连续分数。参数选择集有效待识别图片 1,696 张，独立验证集 2,146 张。

## 5. 本阶段发现的问题

尚未应用接收规则时，第一候选身份正确率只能说明第一候选排序是否正确，不能说明未知人员
是否会被接收。更重要的是，当时缓存先执行启发式质量预筛，导致 1,901 张待识别图片没有
人脸特征向量，分母受到旧质量规则污染。因此阶段 2 结果只保留为发现问题的历史证据，
不能作为最终方法结论。

阶段 3 随后用 10,108 次单因素实验否定旧质量拒绝门槛；阶段 4 建立不含质量预筛的
`RawEmbeddingCache` 并重新提取 13,185/13,233 张自然 LFW 图片；阶段 5B 再用自然
LFW/XQLFW 六场景完成最终联合标定。当前可执行命令以 README 为准。
