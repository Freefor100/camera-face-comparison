## 1. 当时要解决的问题

阶段 2 暴露了两个依赖问题：一是启发式质量预筛拒绝了大量图片，使有效分母被人为
缩小；二是固定一个初始阈值比较不同聚合方法并不公平。执行顺序因此固定为：

```text
原始质量测量与判定分离
  → 只用参数选择集做单因素质量实验
  → 否定或冻结质量规则
  → 重建无质量预筛的自然 LFW 人脸特征向量
  → 保存不含接收参数的连续分数
  → 联合比较聚合与开放集规则
  → 参数冻结后只读一次独立验证集
```

## 2. 阶段 3 质量实验

### 数据隔离

- 只使用 LFW 参数选择集身份，不读取独立验证集；
- 已登记人员 116 个身份，每人一张干净参考图和一张待识别图片；
- 未知人员 300 个来源身份，每个身份最多一张待识别图片；
- 固定种子 `2026`，协议图片和身份均保存到本地 JSON。

### 单因素条件

- 人脸目标尺寸：160、112、96、80、64、48 px；
- 高斯模糊：σ=0、1、2、3、4；
- 亮度倍率：1.0、0.75、0.50、0.35、1.25、1.50；
- 对比度倍率：1.0、0.75、0.50、0.25。

每次只改变一个因素，不做全部条件的笛卡尔组合。分别退化待识别图片和标准库，记录人脸特征提取失败、
原始指标、同人相似度、第一候选身份正确率、未知人员最高分和模型耗时。共完成 10,108 条正式测量，
全部使用实际 CUDA 执行后端。

### 决策

旧质量总分和质量拒绝门槛未能稳定预测识别错误。把阈值设为可保留 99% 干净样本时，
为了移除 2 个待识别图片错误，规则又额外拒绝了 1,053 个正确输入。因此最终删除质量总分、
等级、质量拒绝门槛和样本质量加权；五项
原始指标只作为实验记录和非阻断用户界面提示。

## 3. 阶段 4 自然 LFW 原始链路

质量结论改变了有效输入定义，因此没有复用被预筛污染的阶段 2 结果。重新建立的
`RawEmbeddingCache` 只由数据集、模型提取版本、相对路径和文件 SHA-256 决定：

- 13,233 张图片中 13,185 张得到人脸特征向量，48 张人脸特征提取失败；
- 标准库 7,465 张有效，待识别图片 5,720 张有效；
- 六种聚合共保存 34,320 条连续第一/第二候选分数；
- 缓存复读 13,233 次全部命中，模型推理 0 次。

有身份标签的数据集图片若检测到背景次要人脸，选择面积最大的主体脸；桌面应用仍拒绝
多人脸。判定参数不写入原始人脸特征向量缓存和未应用接收规则的候选分数库。

## 4. 历史自然域扫描与发现

当时比较固定首张参考图片、最高样本分数、人员平均特征向量，以及 K 分别取 2、3、5 的
前 K 个样本分数平均，并扫描最高分阈值和候选分差。候选参数取实际分数发生变化的断点，
不使用反向传播或任意固定网格。

自然 LFW 在严格 `未知人员误接收率≤0.3%` 下产生人员平均特征向量 + 仅候选分差的历史候选：
参数选择集 `未知人员误接收率=0.244%`、`已登记人员正确接收率=61.49%`，独立验证集 `未知人员误接收率=0.252%`、
`已登记人员正确接收率=48.45%`。这暴露出两个问题：

1. 旧扫描器曾用负最高分阈值表示“关闭该条件”，命名不准确；
2. 0.3% 对课程桌面演示过严，且自然 LFW 不能回答跨质量标准库/待识别图片。

阶段 5B 因而重新实现四类明确规则，并把主要约束改为“有效未登记人员误接收率不超过
1%”，同时报告 0.3% 和 10% 两个参考目标。自然域历史结果不再作为部署参数。
