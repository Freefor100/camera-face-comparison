# 阶段 5B 跨质量开放集规则联合标定

数据角色和指标定义见 [术语与内部命名](../术语与内部命名.md)。

> 状态：实验和运行时接入均已完成，结果、参数与局限性见 [阶段 5B 开放集识别规则与跨质量联合标定结果](phase-5b-cross-quality-results.md)。

## 目标

在不重新训练 InsightFace 的前提下，用自然 LFW、XQLFW 待识别图片和混合质量标准库共同
选择一套可部署的人员聚合、开放集接收规则和参数。首先要求参数选择集中四个主要场景的
有效未登记人员误接收率均不超过 1%，随后最大化最差场景的端到端已登记人员正确接收率。

## 固定数据

- 复用阶段 4 的 LFW 标准库、已登记人员/未登记人员图片和身份互斥参数选择集/独立验证集。
- XQLFW 使用与 LFW 相同的 13,233 条相对路径；只补提取缺失人脸特征向量，不改变身份与分区。
- 混合标准库使用种子 `2026`。多样本身份按路径哈希排序后交替使用自然与 XQLFW 图片；单样本身份按身份哈希奇偶固定选择域。
- 前四个主要场景为自然/自然、自然/XQLFW、混合/自然、混合/XQLFW；全 XQLFW 标准库配自然或 XQLFW 待识别图片只作压力测试。

## 候选算法

人员聚合比较固定首张参考图片、最高样本分数、人员平均特征向量和前 K 个样本分数平均；
K 分别取 2、3、5。每种聚合保存前 32 个身份候选，不含任何接收参数。

接收规则必须作为互斥类型报告：

1. `score_threshold`：最高人员分数达到下限；
2. `score_gap`：第一、第二候选分差达到下限；
3. `score_and_gap`：同时满足最高分和候选分差；
4. `nac`：邻域感知余弦规则；人员平均特征向量的前 `k` 个身份分数经过局部归一化指数
   计算（softmax）后，第一候选的相对占比达到下限，`k=2/4/8/16/32`。

所有参数只扫描参数选择集中真实出现的分数断点。禁止使用 `-1` 等哨兵值模拟另一种规则，也不使用独立验证集标签选参。

## 评价与选择

- 有效未登记人员误接收率（`FPIR_valid`）以成功获得人脸特征向量的未登记人员图片为分母，
  用于约束开放集风险。
- 有效已登记人员正确接收率（`TPIR_valid`）只评价有效输入；端到端已登记人员正确接收率
  （`TPIR_e2e`）以协议中全部已登记人员图片为分母，模型失败计为未识别。
- 同时记录第一候选身份正确率、人脸特征提取失败、正确接收、错误身份接收、未登记人员
  被错误接收、耗时和按来源身份重复抽样得到的 95% 置信区间。
- 四个主要场景必须分别满足有效未登记人员误接收率不超过 1%；另报告 0.3% 与 10% 目标。
- 满足误接收率约束后，先最大化最差场景端到端正确接收率，再最大化四个场景的平均值。
- NAC 或候选分差只有在最差场景已登记人员正确接收率比人员平均特征向量 + 最高分阈值至少提高 1 个百分点，并通过参数选择集身份中的小型标准库稳定性复核时才可部署；否则选择简单基线。
- 最终候选冻结后在独立验证集只运行一次，独立验证集超出目标只能记录泛化风险，不能回头改参数。

## 系统交接

实验完成后，应用只接入选中的一套规则。无人脸、多人脸、图片损坏和人脸特征提取失败
继续阻断；人脸尺寸、模糊、亮度和对比度仅记录并提示。启发式质量总分、质量等级、
质量加权的前 K 个样本分数平均和分层识别阈值均已删除；旧配置和开发数据库不兼容。
