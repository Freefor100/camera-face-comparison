# 技术调研：开放集识别规则与人脸质量评估

本文记录本项目从 Phase 2 开始逐步固化的技术选择，作为后续实验设计和课程报告的调研素材。重点不是罗列论文名称，而是说明先进方案、本项目实验结果与课设简化实现之间的边界。

## 1. 调研结论

1. 本项目属于开放集 1:N 身份识别。标准做法是先产生按相似度排序的候选身份，再用在 Calibration 上确定的阈值控制 Unknown 误接收；NIST FRTE 1:N 也在指定 FPIR 工作点报告 FNIR。
2. `score_gap = top_score - second_score` 是可解释的相对拒识特征，但不是 NIST 规定的通用判定条件。Phase 4 在严格工作点选出的结果实际是“仅候选分差”，不能继续笼统标成“阈值加分差”。
3. 聚合方法、匹配阈值和候选分差互相依赖。改变人员聚合会改变最高分及第二分分布，因此必须联合选择，不能先用一套聚合标定阈值再无条件替换聚合。
4. 当前启发式 `quality_score` 只反映检测置信度、尺寸、清晰度、亮度和对比度，不等价于“这张图对身份识别有多大效用”。Phase 3 的 Error-versus-Reject 实验已否定其硬拒绝、质量加权和质量分层阈值用途。
5. 当前人员规模可用 NumPy 精确计算全部余弦相似度。近似向量检索解决的是大规模 Gallery 的速度和内存问题，在本课设中增加依赖但没有实际收益，因此只列为扩展方向。

## 2. NIST FRTE：候选排序、阈值与工作点

### 问题

开放集 1:N 系统如何同时评价 Known 检索和 Unknown 拒识，阈值应该根据什么选择？

### 论文/标准

[NIST Face Recognition Technology Evaluation (FRTE) 1:N Identification](https://pages.nist.gov/frvt/html/frvt1N.html) 将 FPIR 定义为非同源搜索中至少返回一个超过阈值候选的比例，将 FNIR 定义为同源搜索未在阈值以上返回正确身份的比例。NIST 的 identification 表在把 FPIR 限制到 0.003 的阈值上报告 FNIR；无阈值的 investigation 模式则返回固定数量候选供人工复核。

### 复杂方案做法

工业评测通常在大规模 Gallery、多种采集域和严格身份隔离的数据上扫描工作点，同时报告模板生成、检索、存储和不同人群上的误差。部署阈值随算法和数据域确定，不存在脱离模型、Gallery 规模和场景仍普遍最优的常数。

### 本项目采用的简化实现

- 使用固定 Gallery、Calibration 和独立 Evaluation；
- 保存第一候选、第二候选和连续分数，后续不重复提取 embedding；
- 在 Calibration 报告 `FPIR ≤ 1%`、严格参考点 `FPIR ≤ 0.3%` 和宽松参考点 `FPIR ≤ 10%`；
- 本课设以 `FPIR ≤ 1%` 为主目标，在自然、跨质量 Probe 和混合质量 Gallery 上共同选择一套规则；
- 满足各主要场景 FPIR 后最大化最差场景 TPIR，再到 Evaluation 只运行一次最终统计。

### 没有采用的部分及原因

不复现 NIST 的百万级 Gallery、跨人群统计和受控采集协议。本地 LFW 与摄像头数据规模不足，不能把结果表述为 NIST 等级性能。

### 后续可扩展方向

扩大身份数、加入设备/人群分层、置信区间和多 Gallery 规模曲线。它们是完整产品评测方向，不是当前课程 TODO。

## 3. Toward Open-Set Face Recognition：开放集建模

### 问题

直接给余弦相似度加阈值是否就是开放集识别的唯一方案？

### 论文/标准

[Toward Open-Set Face Recognition](https://openaccess.thecvf.com/content_cvpr_2017_workshops/w6/html/Gunther_Toward_Open-Set_Face_CVPR_2017_paper.html) 在开放集协议中比较了阈值化的验证相似度、LDA 得分和 Extreme Value Machine（EVM）概率，并报告 EVM 在其实验中的优势。该论文说明：简单余弦阈值是工程基线，而不是开放集建模的理论终点。

### 复杂方案做法

- LDA（Linear Discriminant Analysis）使用身份标签学习投影矩阵，使类内散度变小、类间散度变大；投影后的向量仍需相似度和拒识规则。它会改变特征空间和候选排序，但本身不是天然的 Unknown 判定器。
- EVM（Extreme Value Machine）用极值理论拟合样本与负样本之间距离尾部，输出对已知类别的包含概率。它需要负样本、尾部大小等超参数，并在 Gallery 改变时维护统计模型。
- 普通余弦阈值不改变第一候选排序，只决定接受还是拒绝；其阈值是一个部署工作点，不是对 embedding 的重新训练。

### 本项目采用的简化实现

使用固定预训练 embedding、人员级余弦分数和数据标定阈值。这样计算链路透明、无需重新训练，适合课程展示和消融。

### 没有采用的部分及原因

不实现 EVM/LDA。LDA 与本项目“单样本身份立即可用”和动态扩容的需求不匹配；EVM 需要额外负样本、概率模型持久化及增量更新。二者都会把课设重点从完整摄像头系统转成开放集分类器复现。

### 后续可扩展方向

在相同协议上加入 EVM 或正则化 LDA 作为附加实验组；除非完成独立标定与评测，否则不替换主系统。

## 4. NAC：邻域感知的开放集接收分数

### 问题

只看最高余弦分数时，如何区分“明显接近一个身份”和“同时靠近多个身份”的 Probe？

### 论文/标准

[Open-Set Face Identification on Few-Shot Gallery by Fine-Tuning](https://arxiv.org/abs/2301.01922) 提出 Neighborhood Aware Cosine（NAC）。它对 Probe 周围最近的 `k` 个身份原型做局部 softmax，以第一候选在邻域中的相对占比作为接收分数。

### 复杂方案做法

论文同时包含权重印刻、仅 BatchNorm 微调和 NAC 匹配器。完整论文收益不是只由 NAC 产生，不能在本项目只实现匹配器后照搬论文结果。NAC 还依赖邻居数和 Gallery 规模，`k` 大于实际身份数时分数分布会变化。

### 本项目采用的简化实现

固定 InsightFace embedding 和 Mean Prototype，只把 NAC 作为无需训练的接收规则候选，与最高分阈值、仅候选分差和二者联合做同协议消融。候选 `k` 为 `2/4/8/16/32`，阈值从实际 NAC 分数断点标定。

### 没有采用的部分及原因

不做论文中的模型微调、分类头训练和权重印刻；最终只允许部署一套在跨质量与小 Gallery 实验中均通过的规则。NAC 若没有带来至少一个百分点的最差场景 TPIR 收益，或对小 Gallery 不稳定，则保留更简单的最高分阈值。

### 后续可扩展方向

使用更大的身份库复现论文的微调和 NAC 联合收益；这属于模型研究，不列入当前课程 TODO。

## 5. Pooling Faces：质量和姿态分组的模板池化

### 问题

同一人员的库内照片质量和角度不齐时，直接使用全部样本是否会被低质量样本拖累？

### 论文/标准

[Pooling Faces: Template Based Face Recognition With Pooled Face Images](https://openaccess.thecvf.com/content_cvpr_2016_workshops/w4/html/Hassner_Pooling_Faces_Template_CVPR_2016_paper.html) 研究了先按图像质量和头部姿态划分模板，再进行池化，以兼顾识别效果、模板数量和比对成本。

### 复杂方案做法

复杂模板系统会估计姿态和质量，把异质图片分成多个子模板，再设计模板到模板的匹配与融合；它不是简单地把所有照片无差别平均。

### 本项目采用的简化实现

Phase 4 在同一批自然 LFW 有效样本上比较 Single、Max、Mean Prototype 和 K=2/3/5 的 Top-K Mean，并联合扫描各自的判定参数。LFW 大 Gallery 的主工作点选择了 Mean Prototype，桌面小 Gallery 仍需域复核。

### 没有采用的部分及原因

当前不做姿态分桶、3D 正面化和多子模板匹配。这些需要稳定的姿态估计、更多每人样本以及新的实验协议，超过当前演示 Gallery 的需求。

### 后续可扩展方向

每个身份按正面/侧面或质量层级建立多个原型；属于模板系统深化方向，不列为本课设必做项。

## 6. NAN 与 QAN：学习式多样本聚合

### 问题

能否让模型自动学习每张图片在人员模板中的权重？

### 论文/标准

[Neural Aggregation Network (NAN)](https://openaccess.thecvf.com/content_cvpr_2017/html/Yang_Neural_Aggregation_Network_CVPR_2017_paper.html) 使用注意力机制聚合视频帧，并自动弱化模糊、遮挡和曝光不当的帧。[Quality Aware Network (QAN)](https://openaccess.thecvf.com/content_cvpr_2017/html/Liu_Quality_Aware_Network_CVPR_2017_paper.html) 通过外观与质量两个分支进行端到端的集合特征聚合。

### 复杂方案做法

权重不是手工亮度或清晰度公式，而是通过身份监督与聚合目标共同学习；训练数据和识别模型共同决定质量的含义。

### 本项目采用的简化实现

主候选只使用不学习参数的确定性聚合。现有启发式质量分只作为历史实验观测量，不进入最终拒识、加权或质量分层阈值。

### 没有采用的部分及原因

不训练注意力/质量网络，也不声称启发式质量分等价于 NAN/QAN 权重。训练成本、数据许可、复现实验和域适配均明显超出课设范围。

### 后续可扩展方向

Phase 3 没有证明启发式质量分有效，因此 Phase 5 不再为它增加质量加权消融。真正的学习式聚合只作为系统局限性后的研究方向。

## 7. PFE：不确定性表示与概率匹配

### 问题

一个确定性的 embedding 能否表达模糊、遮挡等输入造成的不确定性？

### 论文/标准

[Probabilistic Face Embeddings (PFE)](https://openaccess.thecvf.com/content_ICCV_2019/html/Shi_Probabilistic_Face_Embeddings_ICCV_2019_paper.html) 把一张人脸表示为潜在空间中的高斯分布：均值表示最可能特征，方差表达不确定性，并据此进行概率匹配与融合。

### 复杂方案做法

模型除身份特征外还估计逐维不确定性，匹配函数和多样本融合也相应改变。该方法处理的是“特征本身有多不确定”，不是在余弦得分后附加一个图像清晰度权重。

### 本项目采用的简化实现

使用 InsightFace 的确定性 embedding、L2 归一化和余弦相似度。无人脸、多人脸和特征失败属于无效输入；尺寸、模糊、亮度和对比度只记录与提示，不作为身份判定硬门。

### 没有采用的部分及原因

不修改预训练网络输出，不训练方差分支，不实现概率融合。否则模型、缓存格式、匹配规则和标定协议都要整体替换。

### 后续可扩展方向

换用带不确定性输出的模型并重建完整实验，是后续研究项目，不属于本课设 TODO。

## 8. MagFace 与 SER-FIQ：面向识别效用的质量评估

### 问题

清晰、够亮的图片是否一定更适合人脸识别？如何评价一张图片对具体识别模型的效用？

### 论文/标准

[MagFace](https://openaccess.thecvf.com/content/CVPR2021/html/Meng_MagFace_A_Universal_Representation_for_Face_Recognition_and_Quality_Assessment_CVPR_2021_paper.html) 在特征学习中建立特征模长与人脸质量的关系；[SER-FIQ](https://openaccess.thecvf.com/content_CVPR_2020/html/Terhorst_SER-FIQ_Unsupervised_Estimation_of_Face_Image_Quality_Based_on_Stochastic_CVPR_2020_paper.html) 通过随机子网络产生的 embedding 稳定性估计人脸图像质量。两者都把“质量”指向识别效用，而不是一般视觉美观程度。

### 复杂方案做法

MagFace 需要相应训练目标与模型；SER-FIQ 需要可进行随机子网络推理的模型结构和多次前向计算。质量还需通过 Error-versus-Reject 等指标验证。

### 本项目采用的简化实现

保留检测置信度、人脸尺寸、拉普拉斯清晰度、亮度和对比度五项原始指标。Phase 3 用退化实验和 Error-versus-Reject 曲线验证这些指标及其启发式总分，先证明再决定是否参与识别。

### 没有采用的部分及原因

当前 InsightFace ONNX 推理链路不直接提供上述专用 FIQA 输出。额外引入模型会增加离线模型体积、运行时间和新的标定工作，且不能自动保证适配本项目摄像头域。

### 后续可扩展方向

比较专用 FIQA、质量门和简单质量择优；专用 FIQA 不在当前课程 TODO。

## 9. 大规模 Gallery 的近似向量检索

### 问题

身份与样本增长后，逐个计算全部余弦相似度是否仍然合适？

### 论文/标准

[Faiss](https://github.com/facebookresearch/faiss) 提供基于点积/L2 的精确与近似向量索引；归一化向量的点积可实现余弦相似度，并可在速度、内存和召回率之间选择不同索引结构。

### 复杂方案做法

百万或十亿级向量通常采用 IVF、图索引、乘积量化或 GPU 检索，并额外测量召回损失、构建时间、更新成本和内存。

### 本项目采用的简化实现

当前 Gallery 规模小，使用 NumPy 矩阵点积做精确搜索；结果可解释且没有近似召回损失。Phase 5 只在实测证明检索是 E2E 瓶颈时优化。

### 没有采用的部分及原因

不引入近似索引。对于至少 3 人的课程演示，它解决了尚不存在的规模问题，还会增加依赖和动态追加的一致性复杂度。

### 后续可扩展方向

在身份规模达到数万后比较精确矩阵检索与 Faiss 索引，报告召回率、查询耗时、内存和增量更新成本。

## 10. 参数搜索方法

本项目没有使用反向传播搜索 `match_threshold` 或 `min_score_gap`。embedding 和聚合分数固定后，接收规则对两个参数是离散、分段不变的，只有跨过实际 `top_score` 或 `score_gap` 时判定才变化。因此 Phase 4 已完成：

- 最高分阈值、候选分差和 NAC 概率分别在 Calibration 的实际分数断点上扫描；
- 最高分与候选分差联合规则在两个实际断点上做 NumPy 分块精确扫描；
- 用 FPIR 约束和 TPIR/Rank-1 目标选工作点；
- 在独立 Evaluation 上只评估最终方案一次。

这不是“盲目暴力枚举固定小数步长”，也不需要梯度。真正需要重新提取 embedding 的变化只有模型、检测或对齐实现变化；质量测量和判定参数已与原始 embedding 缓存分离。

## 11. 本课设的最终技术边界

本项目选择“固定预训练 embedding + 可解释人员聚合 + 数据驱动开放集规则 + 一个多帧质量择优扩展”。NAC 作为轻量论文匹配器参加实验；EVM、LDA、学习式聚合、概率 embedding、专用 FIQA、姿态子模板和近似检索均在文档中保留研究依据，但不列入课程 TODO，也不把论文效果冒充为本项目效果。
