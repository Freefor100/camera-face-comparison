# 阶段 4 聚合方法与开放集判定联合标定结果

数据角色和指标定义见 [术语与内部命名](术语与内部命名.md)。

> 本文保存自然 LFW、0.3% 严格目标下的历史基线和问题发现过程。它不是最终部署结论；四类明确接收规则、1% 主目标和跨质量联合结果见 [阶段 5B 结果](phase-5b-cross-quality-results.md)。

## 结论

本阶段已完成自然 LFW 全量原始特征重建、六种人员聚合比较、开放集接收参数精确扫描，
以及一次独立验证集。所有聚合方法使用同一标准库、同一待识别图片、同一 InsightFace
`buffalo_l` 人脸特征向量，不使用启发式质量分预筛或加权。

在预先指定的“未知人员误接收率不超过 0.3%”约束下，参数选择集选出的候选方案是：

```text
人员聚合：人员平均特征向量（同一人员的样本向量求均值后重新 L2 归一化）
开放集判定：仅候选分差，score_gap >= 0.5078019499778748
最高分阈值：未启用
```

该方案在参数选择集上的未知人员误接收率/已登记人员正确接收率为 `0.2443% / 61.49%`，锁定参数后在独立验证集上为 `0.2523% / 48.45%`，仍满足 0.3% 未知人员误接收率目标。独立验证集的已登记人员第一候选身份正确率为 `1974/2002 = 98.60%`，说明大部分已登记人员的第一候选身份正确；较低已登记人员正确接收率主要来自严格拒识规则主动拒绝，而不是第一名大量排错。

这只是 LFW 4,599 身份标准库下的算法候选，不直接写入桌面应用配置。候选分差取决于候选人数和数据域，最终部署前仍需使用非最终演示人员的摄像头开发数据复核；最终演示标准库不参与调参。

## 参数选择集与独立验证集

参数选择集是只用于选择聚合方法和判定参数的开发分区；独立验证集是选择完成后才读取一次的独立分区，用来检查选择能否泛化。二者共享同一标准库，但已登记人员图片身份和未知人员来源身份均按身份互斥，不允许同一待识别图片身份跨分区。

| 分区 | 原始待识别图片 | 有效已登记人员 | 有效未登记人员 | 模型失败 |
| --- | ---: | ---: | ---: | ---: |
| 参数选择集 | 2,544 | 1,301 | 1,228 | 15 |
| 独立验证集 | 3,199 | 2,002 | 1,189 | 8 |

标准库包含 4,599 个候选身份和 7,490 张参考图片。参数选择集/独立验证集分别包含 127 个已登记人员图片身份和 575 个未知人员来源身份；两分区身份互斥。

## 六种聚合和历史两类判定实现

下表只使用参数选择集，比较历史的“未知人员误接收率不超过 0.3%”目标。旧扫描器只有
“仅阈值”和“阈值加分差”两个入口，但允许把最高分阈值取为 `-1`。因此人员平均特征
向量第二行实际退化为“仅候选分差”，不能再解释为两个条件同时生效。已登记人员正确
接收率的分母包含所有有效已登记人员，不会把被拒绝人员从分母删除。

| 聚合方法 | 判定 | 匹配阈值 | 最小候选分差 | 第一候选身份正确率 | 已登记人员正确接收率 | 未知人员误接收率 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 固定首张参考图片 | 仅阈值 | 0.6883 | 0 | 98.62% | 42.35% | 0.244% |
| 固定首张参考图片 | 阈值+分差 | 0.6883 | 0 | 98.62% | 42.35% | 0.244% |
| 最高样本分数 | 仅阈值 | 0.8222 | 0 | 98.77% | 7.23% | 0.244% |
| 最高样本分数 | 阈值+分差 | 0.8222 | 0.1494 | 98.77% | 7.23% | 0.244% |
| 人员平均特征向量 | 仅阈值 | 0.7815 | 0 | 98.85% | 50.27% | 0.244% |
| **人员平均特征向量** | **仅候选分差** | **未启用** | **0.5078** | **98.85%** | **61.49%** | **0.244%** |
| 前 K 个样本分数平均, K=2 | 仅阈值 | 0.7272 | 0 | 98.85% | 45.43% | 0.244% |
| 前 K 个样本分数平均, K=2 | 阈值+分差 | 0.7272 | 0 | 98.85% | 45.43% | 0.244% |
| 前 K 个样本分数平均, K=3 | 仅阈值 | 0.7272 | 0 | 98.85% | 37.59% | 0.244% |
| 前 K 个样本分数平均, K=3 | 阈值+分差 | 0.7272 | 0 | 98.85% | 37.59% | 0.244% |
| 前 K 个样本分数平均, K=5 | 仅阈值 | 0.7273 | 0 | 98.62% | 19.45% | 0.244% |
| 前 K 个样本分数平均, K=5 | 阈值+分差 | 0.7273 | 0 | 98.62% | 19.45% | 0.244% |

人员平均特征向量的仅候选分差规则比同方法仅阈值多接收 `800 - 654 = 146` 个正确已登记
人员，而未登记人员误接收仍为 3 个，因此在 0.3% 严格目标下不能直接排除候选分差。
但该结论不代表“阈值加分差”有效，也不能代替在 1% 目标和跨质量场景下重新比较四类
明确规则。

目标误接收率的影响也必须保留：允许未知人员误接收率最高为 1% 时，人员平均特征向量只用
阈值即可达到 97.85% 已登记人员正确接收率；要求参数选择集中观测误接收为 0 时，已登记
人员正确接收率只有 0.85%。这表明阈值不存在脱离风险目标的“通用最优值”。

## 独立验证集

参数在查看独立验证集标签前已经固定：先满足目标未知人员误接收率，再最大化已登记人员
正确接收率；效果相同时优先不使用候选分差，随后优先选择人员表示更紧凑、检索开销更低
的方法。

| 指标 | 参数选择集 | 独立验证集 |
| --- | ---: | ---: |
| 已登记人员有效数 | 1,301 | 2,002 |
| 已登记人员第一候选身份正确率 | 1,286（98.85%） | 1,974（98.60%） |
| 正确接收已登记人员 | 800 | 970 |
| 错误接收已登记人员 | 2 | 4 |
| 未知人员有效数 | 1,228 | 1,189 |
| 错误接收未知人员 | 3 | 3 |
| 已登记人员正确接收率 | 61.49% | 48.45% |
| 已登记人员未正确识别率 | 38.51% | 51.55% |
| 未知人员误接收率 | 0.244% | 0.252% |

独立验证集达到预设未知人员误接收率目标，但已登记人员正确接收率比参数选择集下降 13.04 个百分点。这不是继续读取独立验证集反复调参的理由；该泛化风险随后通过阶段 5B 的自然/XQLFW 四场景共同选参重新评估。

## 当前边界与交接

- `人员平均特征向量 + 仅候选分差` 是自然 LFW 大型标准库在 0.3% 严格目标下的历史候选，
  已经被阶段 5B 的跨质量联合标定取代。
- `score_gap=0.5078` 对标准库候选身份数量和人员组成敏感；最终只有少量身份的最终演示标准库不能直接声称拥有相同未知人员误接收率/已登记人员正确接收率。
- 阶段 3 已否定启发式质量总分的硬拒绝、加权和质量分层阈值用途；当前桌面应用已经删除这套旧部署策略并接入阶段 5B 最终规则。
- XQLFW 没有参与本轮历史选择，但已在阶段 5B 与 LFW 同路径构成四个联合选参场景；QMUL-SurvFace 仍只作监控小脸压力测试。
