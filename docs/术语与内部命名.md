# 术语与内部命名说明

本文解释项目代码、评测报告和开发文档中出现的英文名称、缩写和算法标签。后续新增名称时，第一次出现必须同时给出中文含义和代码标识，不能只写缩写。

## 识别任务术语

| 名称 | 中文含义 | 在本项目中的具体含义 |
| --- | --- | --- |
| `1:1 verification` | 一对一验证 | 判断两张图片是否属于同一人；XQLFW 使用此任务，不负责本项目的多身份检索排名 |
| `1:N identification` | 一对多身份识别 | 一张待识别图片与标准库中的 N 个身份比较，输出某个身份或 Unknown |
| `Gallery` | 标准库 / 注册参考集 | 已注册身份的参考图片及其 embedding；每个身份可以有多张样本 |
| `Probe` | 待识别探针 | 送入系统进行检测、特征提取和检索的图片 |
| `Known Probe` | 已知身份探针 | 身份已经出现在 Gallery，但该张图片没有被放入 Gallery |
| `Unknown Probe` | 未知身份探针 | 身份完全没有出现在 Gallery，用于测试开放集拒识 |
| `Identity` / `person` | 身份 / 人员 | 一个需要被区分的人员；代码中通常使用 `person_id` |
| `Reference Sample` | 标准样本 | 某个身份在 Gallery 中的一张参考图片及其 embedding |
| `embedding` | 人脸特征向量 | InsightFace 从人脸图像提取的数值向量；本项目保存 L2 归一化后的 `float32` 向量 |
| `Query` | 查询向量 | Probe 经检测和特征提取后得到的向量，代码中通常叫 `query_embedding` |

## 相似度、聚合和判定

| 名称 | 中文含义 | 当前实现 |
| --- | --- | --- |
| `cosine similarity` | 余弦相似度 | 归一化向量的点积 `q · e`，分数越高表示越相似 |
| `cosine distance` | 余弦距离 | 通常定义为 `1 - cosine_similarity`；当前识别代码直接使用相似度，不使用距离 |
| `person score` | 人员级分数 | 某个身份的多张样本分数经过一种聚合策略后得到的分数 |
| `top_score` | 第一候选分数 | 所有身份级分数中的最高值 |
| `second_score` | 第二候选分数 | 所有身份级分数中的第二高值；只有一个身份时为空 |
| `score_gap` / `min_score_gap` | 候选分差 / 最小候选分差 | `top_score - second_score` 及其下限；分差小表示候选接近，不是余弦距离或向量模长 |
| `match_threshold` | 身份匹配阈值 | 第一候选人员分数必须达到的最低值；当前默认值是初始值，未完成正式 Calibration |
| `Single` | 单样本控制方法 | 固定使用每个身份 Gallery 中第一张有效样本，不随机抽样 |
| `Max` | 最大样本分数方法 | 取该身份所有参考样本相似度的最大值 |
| `Mean Prototype` | 平均原型方法 | 先平均该身份的所有 embedding，再归一化得到原型，查询向量与原型计算相似度 |
| `Top-K Mean` / `top_k_mean` | 前 K 样本普通平均 | 取该身份相似度最高的 K 张样本后做普通算术平均；Phase 2 固定比较 K=2、3、5 |
| `quality-weighted Top-K` | 质量加权前 K 聚合 | 当前桌面应用仍在运行的初始策略；按参考图启发式质量分加权，不属于 Phase 2 六组主候选，后续由实验决定保留或删除 |
| `K` / `top_k` | 参与聚合的样本数量 | 当前配置默认 `top_k = 3`；样本少于 K 张时使用全部样本 |
| `Unknown` | 未知人员 | 第一候选低于阈值，或第一、第二候选分差不足时的正常业务结果 |
| `Invalid` / `Low Quality` | 无效 / 低质量输入 | 无脸、多人脸、脸过小、模糊、亮度或对比度不合格等，不进入身份判定 |

## 质量检查名称

| 名称 | 中文含义 | 检查内容 |
| --- | --- | --- |
| `quality gate` | 质量门 | 身份比对前的输入筛查，不只检查图像像素尺寸 |
| `detection_score` | 检测置信度 | InsightFace 对检测框的人脸置信度 |
| `face_size_px` | 人脸像素尺寸 | 检测框宽高较小值，用于拒绝过远或过小的人脸 |
| `blur_variance` | 清晰度指标 | 人脸区域拉普拉斯方差，用于发现明显模糊 |
| `brightness` | 亮度 | 人脸区域平均亮度，用于发现过暗或过曝 |
| `contrast` | 对比度 | 人脸区域像素标准差，用于发现对比度过低 |
| `QualityProfile` | 质量档案 | 保存质量层级、质量分数、各项指标和拒绝原因的对象 |
| `high` / `medium` / `reject` | 高质量 / 中等质量 / 拒绝 | 当前质量分层名称；分层可选择不同识别阈值 |

当前质量门不包含专门的姿态角估计、遮挡识别、活体检测或论文级 FIQA 模型；关键点会被 InsightFace 用于对齐和输出，但当前应用没有把姿态单独作为拒绝条件。

## 评测指标和数据集

| 名称 | 中文含义 | 解释 |
| --- | --- | --- |
| `Rank-1` / `TPIR` | 第一名正确率 / 真阳性识别率 | Known Probe 被正确识别为真实身份的比例 |
| `FPIR` | 错误识别率 | Unknown Probe 被错误分配给 Gallery 身份的比例 |
| `FNIR` | 漏识别率 | Known Probe 被拒绝或识别为错误身份的比例 |
| `FTE` | 特征提取失败 | 无法检测或提取有效 embedding 的输入比例/数量 |
| `FTA` | 录入失败 | Gallery 样本无法通过录入质量门的比例/数量 |
| `Calibration` | 阈值标定集 | 只用于选择阈值和必要参数，不用于报告最终效果 |
| `Evaluation` | 独立评测集 | 与 Calibration 隔离，只用于最终报告效果 |
| `LFW` | Labeled Faces in the Wild | Phase 2 固定无阈值分数，Phase 3 验证质量门，Phase 4 联合标定 |
| `XQLFW` | Cross-Quality LFW | Phase 5 的跨质量鲁棒性数据集，官方任务是 1:1 verification |
| `QMUL-SurvFace` | 监控场景人脸数据集 | Phase 5 的小脸、远距离和监控域压力测试数据集 |

## 项目代码对象

| 代码名称 | 职责 |
| --- | --- |
| `FaceEngine` | 调用 InsightFace，完成检测、关键点、对齐链路和 embedding 提取 |
| `RecognitionService` | 连接输入图片、质量门、标准库、识别判定和日志 |
| `FaceRepository` | 保存和读取人员、样本、embedding、图片哈希及识别日志 |
| `EvaluationEmbeddingCache` | 为长数据集评测保存可恢复的 embedding 或拒绝结果 |
| `LfwProtocol` | 保存 Gallery 与 Known/Unknown Probe 的固定相对路径划分 |
| `LfwSplitProtocol` | 在质量过滤前按来源身份固定 Calibration/Evaluation 的协议 |
| `decision_scores.sqlite` | 保存六种聚合的第一/第二候选连续分数和拒绝项，不含判定阈值 |
| `embedding_extraction_id` | 只标识会改变有效输入或 embedding 的模型、检测和质量规则 |
| `decision_policy_id` | 标识聚合、匹配阈值和候选分差等判定参数 |
| `QualityProfile` | 表示一张人脸图片的质量结果 |
| `RecognitionResult` | UI 和日志共用的一次识别结果 |
| `ExecutionBackend` | 表示实际使用的 CUDA 或 CPU 推理后端 |

## 命名与报告规则

- 代码中的 `gallery`、`probe`、`person_scores`、`top_k` 等名称必须与本文含义一致。
- 报告首次出现 `TPIR`、`FPIR`、`FNIR`、`FTE`、`FTA` 时必须写中文全称或链接到本文。
- `Unknown` 是正常的开放集业务判定；`Invalid` 是输入或数据质量问题；两者不能混写。
- 方法比较看同一批 Probe 上的 TPIR、FPIR、FNIR、拒绝数量和耗时；候选分差只是待消融的判定特征，不以分差本身越大或越小为优化目标。
