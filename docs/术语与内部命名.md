# 术语与内部命名说明

本文解释代码、实验报告和开发文档中的术语。新增缩写或算法标签时，第一次出现必须同时
写出中文含义和内部名称。

## 识别任务

| 名称 | 中文含义 | 本项目中的具体含义 |
| --- | --- | --- |
| `1:1 verification` | 一对一验证 | 判断两张图片是否同人；XQLFW 官方 Pair 属于该任务 |
| `1:N identification` | 一对多身份识别 | 一张 Probe 在 N 个 Gallery 身份中检索，随后接收某身份或拒为 Unknown |
| `open-set` | 开放集 | 输入既可能属于 Gallery 已知身份，也可能是不在库中的人 |
| `Gallery` | 标准库 / 注册参考集 | 已注册身份及其一张或多张参考图片、embedding |
| `Probe` | 待识别探针 | 送入系统进行检测、特征提取和检索的图片 |
| `Known Probe` | 已知探针 | 人在 Gallery 中，但当前图片没有入库 |
| `Unknown Probe` | 未知探针 | 人完全不在 Gallery 中，用于测拒识能力 |
| `Calibration` | 参数标定集 | 只用于选择算法和阈值，不用于报告最终泛化效果 |
| `Evaluation` | 独立评测集 | 参数冻结后执行一次，不能再反过来调参 |
| `embedding` | 人脸特征向量 | InsightFace 产生的 512 维向量；保存和比对前做 L2 归一化 |

## 人员表示与分数

| 名称 | 中文含义 | 本项目中的定义/状态 |
| --- | --- | --- |
| `cosine similarity` | 余弦相似度 | 单位向量点积 `q · e`，范围 `[-1,1]`，越高越相似 |
| `cosine distance` | 余弦距离 | 通常是 `1 - similarity`；当前运行时不使用距离或向量模长判定 |
| `Single` | 固定单样本对照 | 每个身份固定用路径排序后的第一张有效样本，不是每次随机抽一张 |
| `Max` | 最大样本分数 | 取某身份所有样本相似度的最大值 |
| `Mean Prototype` | 平均身份原型 | 先平均该身份全部单位 embedding，再归一化；当前部署聚合方法 |
| `Top-K Mean` | 前 K 分数普通平均 | 取某身份最高 K 个样本分数求平均；实验比较 K=2/3/5，未部署 |
| `person score` | 人员级分数 | Query 与某身份表示之间的最终连续分数 |
| `top_score` | 第一候选分数 | 所有人员级分数中的最高值 |
| `second_score` | 第二候选分数 | 第二高值；库中只有一个身份时为空 |
| `score_gap` | 候选分差 | `top_score - second_score`；当前显示和记录，但不参与部署判定 |
| `minimum_score` | 最低接收分数 | 当前部署阈值 `0.5557855367660522`，来自跨质量 Calibration 联合标定 |
| `minimum_gap` | 最小候选分差 | 仅候选分差/双条件实验参数；当前部署配置中不存在 |
| `score_threshold` | 最高分阈值规则 | `top_score >= minimum_score`；当前唯一部署规则 |
| `score_gap` rule | 仅候选分差规则 | 只检查候选分差；完成实验但未部署 |
| `score_and_gap` | 双条件规则 | 同时检查最高分和候选分差；完成实验但未部署 |
| `NAC` | 邻域感知余弦 | 对前 K 个身份分数做局部 softmax 的论文对照；收益不足，未部署 |

## 结果状态与质量指标

| 名称 | 中文含义 | 当前行为 |
| --- | --- | --- |
| `matched` | 已识别 | 第一候选通过 `minimum_score`，输出其姓名 |
| `unknown` | 未知人员 | 已完成有效检索，但第一候选分数不足 |
| `invalid` | 无效输入/系统数据 | 图片损坏、无人脸、多人脸、无效 embedding 或标准库完整性失败 |
| `FTE` | 特征提取失败 | 图片无法得到有效人脸 embedding |
| `detection_score` | 检测置信度 | InsightFace 对检测框的人脸置信度 |
| `face_size_px` | 人脸像素尺寸 | 检测框宽高较小值 |
| `blur_variance` | 清晰度指标 | 人脸区域的拉普拉斯方差 |
| `brightness` | 亮度 | 人脸区域平均像素值 |
| `contrast` | 对比度 | 人脸区域像素标准差 |
| `quality_warnings` | 质量提示 | 根据原始指标给出靠近、稳定或改善光照等建议；不阻断录入和识别 |

Phase 3 曾实验一个把五项指标线性组合的启发式质量总分和分级硬门。Error-versus-Reject
结果表明它会拒绝大量本来识别正确的图片，因此相关运行时代码已删除。当前不存在质量等级、
质量权重或“低质量自动等于 Unknown”的逻辑。原始指标保留用于 UI 提示、实验和日志。

## 评测指标

| 名称 | 中文含义 | 分母与解释 |
| --- | --- | --- |
| `Rank-1` | 第一候选身份正确率 | Known 有效 Probe 中，排序第一是否为真实身份；与接收阈值无关 |
| `TPIR_valid` | 有效输入真阳性识别率 | 有效 Known Probe 中，被正确身份接收的比例 |
| `TPIR_e2e` | 端到端真阳性识别率 | 全部协议 Known 图片中，被正确身份接收的比例；包含 FTE 代价 |
| `FPIR_valid` | 有效 Unknown 误接收率 | 有效 Unknown Probe 被错误接受为任一已知身份的比例 |
| `FNIR` | 漏识别率 | Known 被拒绝或接收成错误身份的比例 |
| `FTA` | 录入失败 | Gallery 图片无法形成有效样本的数量/比例 |

## 主要代码对象

| 代码名称 | 职责 |
| --- | --- |
| `FaceEngine` | 调用 InsightFace，输出检测框、关键点和归一化 embedding |
| `RecognitionService` | 连接完整性检查、输入、Mean Prototype、阈值判定和日志 |
| `FaceRepository` | 保存人员、样本、原始质量指标、哈希和识别日志 |
| `RawEmbeddingCache` | 保存与接收参数无关的原始 embedding、指标、FTE 和耗时 |
| `LfwProtocol` | 固定 Gallery 与 Known/Unknown Probe 路径 |
| `LfwSplitProtocol` | 在图片过滤前按身份固定 Calibration/Evaluation |
| `decision_scores.sqlite` | 保存多种聚合的连续候选分数，不保存任何接收参数 |
| `JointOperatingPoint` | 一种聚合、接收规则及其 Calibration 工作点 |
| `RecognitionResult` | UI 与数据库日志共用的一次识别结果 |
| `ExecutionBackend` | 实际使用的 CUDA 或 CPU 推理后端 |

## 报告规则

- Unknown 是正常开放集结果，Invalid 是输入/数据失败，不能混写。
- 方法比较必须使用同一 Gallery、Probe、模型和有效分母，并分别报告排序能力和接收能力。
- 候选分差不是余弦距离，也不是越大就代表系统整体越好；是否使用由同条件消融决定。
- Calibration 只负责选参；Evaluation 的结果即使略低于目标，也不能反复调参美化。
- XQLFW 官方 6,000 Pair 是 1:1；同路径 LFW/XQLFW 六场景才是本项目的跨质量 1:N 实验。
