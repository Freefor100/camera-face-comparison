# 阶段 2：固定评测数据与连续候选分数

> 本阶段产物用于阶段 3 质量验证和阶段 4 联合标定。它不使用当前阈值选最终方法，也不修改应用配置。

> 后续状态：阶段 3 已证明本阶段质量预筛过严，阶段 4 已重建自然 LFW 原始缓存并完成联合标定。本页保留为历史诊断，正式算法结果见 [阶段 4 结果](phase-4-results.md)。

“连续候选分数”指尚未应用接收阈值的人员分数。统一术语见
[术语与内部命名](术语与内部命名.md)。

## 1. 连续候选分数产物

运行日期：2026-09-08。源数据为本地 LFW 13,233 张图片，模型为已经完成缓存的 InsightFace `buffalo_l`。本轮只读取缓存，没有重新初始化或运行 InsightFace。

本地产物位于 `data/experiments/phase2/`：

- `protocol.json`：固定参数选择集/独立验证集分区；
- `decision_scores.sqlite`：逐待识别图片、逐方法的第一/第二候选连续分数；
- `calibration_summary.json`：参数选择集的候选分数覆盖和第一候选身份正确率摘要；
- `evaluation_summary.json`：独立验证集的候选分数覆盖和第一候选身份正确率摘要；
- `manifest.json`：协议、缓存、质量配置、代码版本和覆盖统计。

这些文件包含数据集路径和实验结果，被 Git 忽略。

## 3. 六种方法的第一候选身份正确率

下表只检查“真实已登记人员身份是否排在第一名”，不执行未知人员接收，因此不能据此选择开放集最终方法。

| 方法 | 参数选择集第一候选身份正确率 | 独立验证集第一候选身份正确率 |
| --- | ---: | ---: |
| 固定首张参考图片 | 913/917（99.56%） | 1363/1364（99.93%） |
| 最高样本分数 | 914/917（99.67%） | 1363/1364（99.93%） |
| 人员平均特征向量 | 914/917（99.67%） | 1363/1364（99.93%） |
| 前 K 个样本分数平均, K=2 | 914/917（99.67%） | 1363/1364（99.93%） |
| 前 K 个样本分数平均, K=3 | 914/917（99.67%） | 1363/1364（99.93%） |
| 前 K 个样本分数平均, K=5 | 914/917（99.67%） | 1363/1364（99.93%） |

结论仅限于：固定首张参考图片方法在参数选择集少命中 1 张，其余方法在这批有效已登记
人员图片上的第一名排序差异很小。未知人员是否会被误接收取决于各方法的第一候选分数
分布和后续接收参数，必须在阶段 4 联合标定后判断。独立验证集在选定最终方案前不会用于
反复调参。

## 4. 历史固定阈值诊断

早前 `data/logs/lfw_full_algorithm_baseline.json` 在未完成身份互斥参数选择集的情况下，直接使用初始阈值和质量层策略比较四种方法。该结果只保留为“为什么需要重构评测链路”的历史证据：

| 历史方法 | 已登记人员正确 / 2,281 | 未知人员拒识 / 1,561 | 未知人员误接收率 | 已登记人员未正确识别率 |
| --- | ---: | ---: | ---: | ---: |
| 固定首张参考图片 | 2,015 | 1,558 | 0.19% | 11.66% |
| 最高样本分数 | 2,188 | 1,556 | 0.32% | 4.08% |
| 人员平均特征向量 | 2,226 | 1,555 | 0.38% | 2.41% |
| 历史质量加权的前 K 个样本分数平均 | 2,113 | 1,557 | 0.26% | 7.37% |

这些数字随阈值变化，且各方法的分数尺度不同，不能用一套初始阈值公平决定最终方法。
历史质量加权的前 K 个样本分数平均也不属于当前六种普通聚合候选。

早期 7 张有效待识别图片的小规模试运行同样只作为链路连通性测试：固定首张参考图片方法
识别正确 2/4，最高样本分数和人员平均特征向量均为 4/4，历史质量加权方法为 3/4；
3 张未登记人员图片均被拒绝。该样本量不承担算法结论。

## 5. 历史结论和后续完成状态

阶段 2 已完成“固定数据 + 缓存人脸特征向量 + 保存未应用接收规则的候选分数”，解决了反复运行模型和阈值变化污染方法比较的问题。

本阶段结束时确定的依赖顺序及后续完成情况为：

1. 阶段 3 已验证人脸尺寸、模糊、亮度、对比度和旧启发式质量总分，结论是删除没有实验证据支持的质量拒绝门槛；
2. 阶段 4 已重建 13,185 条无质量预筛的自然 LFW 人脸特征向量；
3. 阶段 5B 已在参数选择集上联合比较六种聚合、四类规则和邻域感知余弦；
4. 当前部署已选择人员平均特征向量 + 最高分阈值 `0.5557855`，并只执行一次独立验证集。

XQLFW 和 QMUL-SurvFace 的正式结果已经分别记录在阶段 5/5B 文档；本页继续只承担历史问题证据。
