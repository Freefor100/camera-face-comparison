# 数据集实验与参数依据

本目录保存课程设计开发期间使用的数据集协议、参数标定、鲁棒性分析和性能对照代码。这里的
内容用于说明识别规则和优化结论是如何得到的，不参与桌面程序启动，也不需要在课堂演示时逐个
讲解。

- `face_evaluation/` 保存数据集协议、特征缓存、候选分数、参数搜索和统计模块；
- `commands/` 保存 LFW、XQLFW、QMUL-SurvFace 以及性能实验命令；
- `tests/` 保存只针对实验协议和统计公式的自动化测试；
- 实验结论和阶段记录统一保存在 `docs/experiments/`；
- 大型图片、模型、特征缓存和实验结果仍保存在被 Git 忽略的 `data/`。

实验命令从项目根目录以 Python 模块方式运行。例如：

```bash
.venv/bin/python -m experiments.commands.evaluate_xqlfw --data-dir ./data
```

最终桌面程序不依赖本目录。删除本目录后，已经安装的桌面应用仍可使用；但课程报告将失去算法
选择和优化前后对照所对应的可复现实验代码，因此项目继续保留这些内容。
